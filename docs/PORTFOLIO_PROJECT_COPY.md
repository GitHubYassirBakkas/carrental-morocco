# Portfolio Project Copy

## Project Title

CarRental Morocco

## One-Line Summary

Full-stack Laravel car-rental platform for Morocco with bookings, Stripe payments, driver verification, admin operations, and EN/FR/AR localization.

## Short Description

CarRental Morocco is a portfolio-ready Laravel 12 application that models a complete rental workflow: customers browse vehicles, verify driver details, select insurance, apply coupons, book rentals, pay through Stripe or a cash path, receive invoices, and manage support. Admins manage cars, bookings, invoices, refunds, driver verification, support tickets, reviews, locations, settings, and rental lifecycle operations.

## Key Features

- Multilingual customer experience in English, French, and Arabic with RTL support.
- Vehicle catalog with search, filters, availability dates, and wishlist.
- Booking flow with driver verification, insurance selection, coupons, invoices, and notifications.
- Stripe rental payments plus separate security deposit authorization.
- Admin dashboard for bookings, cars, invoices, refunds, reviews, support, locations, settings, and driver verification.
- Rental lifecycle tools for confirmation, start, completion, inspections, damage evidence, and deposit release/capture.
- Security-focused architecture with private documents, rate limiting, webhook verification, idempotency, queues, and tests.

## Tech Stack

Laravel 12, PHP 8.2+, Blade, Tailwind CSS, Alpine.js, Vite, Stripe PHP, Resend, Dompdf, Pest, Laravel Pint, SQLite/MySQL.
